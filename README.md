 Anime Figure Store Website

An interactive and visually appealing Anime Figure Store web application inspired by a Figma design. This project focuses on a clean UI, smooth user experience, and modern frontend development practices.



🚀 Features

Modern anime-themed UI

Responsive design (desktop & mobile friendly)

Product listing layout for anime figures

Clean component-based structure

Fast development setup using modern tooling

🛠️ Tech Stack

Frontend Framework: React / Vite (based on your setup)

Styling: CSS / Tailwind / Styled Components (as used in project)

Package Manager: npm

Design Tool: Figma

📂 Project Setup

Follow the steps below to run the project locally:

1️⃣ Install Dependencies
npm install

2️⃣ Start Development Server
npm run dev


The app will start running on the local development server. Open your browser and navigate to the URL shown in the terminal.
